# HMB GP Production Team v0.8.71

Local v0.8.72에서 검증한 기능과 UI를 팀 배포에 포함합니다. 기존 v0.8.65의 저장본 샷 복원 수정도 유지합니다.

- 11개 라이브러리, 13개 위젯과 시작 화면·통합 헤더 이미지 6장을 포함합니다. Analysis Agent와 로동마트도 포함합니다.
- Editor 0.130.0 / SDK 0.104.0에서 통합 헤더, 연결 관리, 삭제 보호와 Git Update/Override 설치 경로를 보완했습니다.
- 샷별 Picker 장면 읽기·저장·복원과 다른 샷의 영상 이어붙이기를 지원합니다. 기존 영상과 샷 바인딩을 보존합니다.
- 가져온 참조 영상과 DCC Playblast의 역할을 구분합니다. 분석 결과의 영상 출처와 현재 참조 번호를 Agent와 Generator 전달에 유지합니다.
- 한글 Prompt 입력, 샷별 저장·복원, 한글 분석문과 원문 보존 문구를 현재 SDK 요청 직렬화 및 브라우저 검사로 확인했습니다.

## 업데이트

기존 사용자는 Griptape의 HMB Git 라이브러리에서 **Git Update/Override**를 적용한 뒤 작업을 저장하고 Griptape를 완전히 종료·재시작합니다. 새 사용자는 같은 Git 라이브러리를 등록합니다. 원래 저장본, 미디어, 인증과 샷 식별자를 유지하며, 운영 서버 기능에는 각 팀원의 인증이 필요합니다.

## 확인한 범위

설치된 Local의 런타임 69개 파일과 대조했습니다. 업무 로직·위젯 파일 67개는 동일하며, 나머지 2개는 버전과 설치 초기화 경로의 차이입니다. Editor 0.130의 생성된 통합 모듈도 Local과 동일합니다. ZIP의 설치 파일 69개와 배포 지원 파일 22개, 서명된 Agent DAT 및 필수 UI 이미지 포함 여부를 검사했습니다.

기존 검증 기록에 현재 SDK의 영상·분석 전달 검사 17종과 한글 경계 검사 4종을 더했습니다. 이 검사는 격리된 SDK·브라우저·전송 대역을 사용했습니다. 이번 릴리스 준비에서 유료 생성이나 별도 팀원 Desktop 재실행은 하지 않았습니다. GitHub Actions의 실행 결과는 해당 커밋의 검사 기록에서 별도로 확인합니다.
