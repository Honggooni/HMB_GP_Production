# Griptape Nodes Desktop 0.31.0까지의 공식 배포 이력과 HMB 영향

2026년 11월 24일 조사. 공식 Stable 업데이트 목록 5개에서 Desktop 버전 **114개**를 확인했다. 정식 번호 110개와 목록에 보존된 RC 4개다. 버전별 변경 설명이 확인된 것은 **29개**다. 나머지 **85개**는 배포 식별자는 확인되지만 조사한 공식 피드·통합 변경 기록에 개별 설명이 없다. 아래의 과거 목록은 배포 자료 조사 결과이며 실행 검증 범위는 별도 표에 적었다. [Windows Stable 피드](https://downloads.griptapenodes.com/stable/releases.win-x64-stable.json) · [공식 통합 변경 기록](https://github.com/griptape-ai/griptape-nodes-changelog/blob/09a6a47e43787ff36e751eae6c5015ce8d8b9d94/CHANGELOG.md)

### 0.31.0에서 실제로 바뀐 것

- 작업 PC의 Windows 패키지는 Desktop **0.31.0**, Python 패키지/App **0.106.0**, Engine **0.113.0**, Editor **0.132.0**이다. 이전 Desktop 0.30.4의 조합은 **0.104.3 / 0.108.1 / 0.130.3**이었다. HMB가 관례적으로 SDK라고 부르는 숫자는 Python 배포판 `griptape-nodes`의 버전이다. 실행 요청과 워크플로 계약에는 별도 Engine 버전도 필요하다. [공식 통합 릴리스](https://github.com/griptape-ai/griptape-nodes-changelog/blob/09a6a47e43787ff36e751eae6c5015ce8d8b9d94/CHANGELOG.md) · [설치 정보 확인 위치](https://docs.griptapenodes.com/en/stable/guides/desktop/app_settings/)
- 작업 PC의 Standard Library는 매니페스트에서 **0.91.1**을 선언한다. 실제 체크아웃은 조사 시점의 로컬 `nightly` 태그 `29e91f36`이고, 공식 `v0.91.1` 태그 `3c003e1d`보다 7커밋 앞선다. 추적 파일의 미커밋 변경은 0개였다. 팀 PC도 같다고 단정할 수 없다. Agent 모델과 Seedance 기능을 비교할 때는 매니페스트와 Git 커밋 둘 다 기록해야 한다. [Standard 정식 릴리스](https://github.com/griptape-ai/griptape-nodes-library-standard/releases/tag/v0.91.1) · [작업 PC와 같은 소스](https://github.com/griptape-ai/griptape-nodes-library-standard/tree/29e91f362343e2eba4fb3d2d48ef05d43bb34d53)
- Editor 131은 Engine 0.109.0 이상을 요구하고 워크플로별 탭·상태 표시를 도입했다. Engine 0.109.0이 탭별 워크플로를 열고 닫는 요청을 제공했고, App 0.105.0은 CLI와 진행 이벤트에 워크플로 식별자를 반영했다. Editor 132와 Engine 0.113.0에서는 프로젝트 변경·탭 닫기·미저장 변경을 다루는 동작도 바뀌었다. Desktop 버전 한 개가 여러 독립 릴리스의 변화를 함께 전달한 사례다. [Editor·App 이력](https://github.com/griptape-ai/griptape-nodes-changelog/blob/09a6a47e43787ff36e751eae6c5015ce8d8b9d94/CHANGELOG.md) · [Engine 0.109.0](https://github.com/griptape-ai/griptape-nodes-engine/releases/tag/v0.109.0) · [Engine 0.113.0](https://github.com/griptape-ai/griptape-nodes-engine/releases/tag/v0.113.0)

| 바뀌는 접점 | 실제로 영향받는 작업 | 업데이트 후보에서 구분해 확인할 결과 |
| --- | --- | --- |
| Desktop·Editor 시작 화면과 공통 노드 헤더 | 11개 노드의 본문이 열려도 샷 선택·렌더 버튼 또는 로동마트 시작 카드가 사라질 수 있다 | 같은 Editor 빌드에서 헤더 11개 표시, 시작 카드 클릭, 지정한 새 탭에서 바구니 1회 준비까지 확인한다 |
| App·Engine의 워크플로별 요청 | 두 탭에 같은 노드·플로 이름을 쓰면 Agent 점검, Generator 요청, 재열기와 연결 보호가 서로 간섭할 수 있다 | 동명 A/B 탭에서 실제 SDK 요청으로 대상 탭의 연결·샷만 바뀌는지 확인한다. 저장 탭과 미저장 탭을 닫고 B의 선·원격 바인딩·저장본을 대조한다 |
| Editor 공식 위젯 API와 HMB의 헤더 확장 | 노드 내부 컨트롤과 편집기 상단 버튼의 고장 범위가 다르다 | 네이티브 헤더 없이 위젯 본문을 열어 본문 컨트롤을 확인하고, 새 공식 번들에서 헤더와 시작 화면을 따로 검증한다 |
| Standard Agent의 모델 목록·드라이버·자격 증명 | 공급자/모델 기본값, 연결을 풀었을 때의 드롭다운, 저장본을 다시 열었을 때의 모델이 달라질 수 있다 | 같은 Standard 커밋의 기본 Agent와 HMB Agent에서 선택지·기본값·실제 실행 요청의 모델을 비교한다 |
| Standard Seedance와 HMB Generator | Standard의 해상도·Draft·참조 입력 지원이 늘어나도 HMB 브로커의 접수·중복 방지는 별도로 동작한다 | 표준 기능 표면을 비교한 다음 Only/샷 바인딩, 참조 이미지, 480p Draft와 1080p·4K Final을 HMB 경로에서 검증한다. 화면 표시·무과금 요청 검증·실제 유료 결과를 구분한다 |

### 언제부터 확인할 수 있는가

Desktop 출시 공지 본문은 **2025-11-17**에 Windows·macOS·Linux용 다운로드를 안내했다. 그 공지에는 패키지 버전이 없다. 현재 Stable 목록에서 확인되는 가장 이른 번호는 **0.2.0-rc.6**, 가장 이른 정식 번호는 **0.2.1**이다. 당시의 최초 공개 빌드 번호·시각, 목록 작성 이전 삭제된 빌드는 이 자료로 특정할 수 없다. 2025년 12월 공식 공지는 Library Manager에서 라이브러리를 추가하는 방법을, 2026년 5월 공지는 노드의 사용자 정의 위젯을 소개한다. 두 기능을 특정 Desktop 패치에 귀속할 자료는 확인하지 못했다. ### 재현과 근거

1. 위 5개 Stable JSON의 `Assets`에서 `Version`의 집합을 합친다. 정식 번호는 정규식 `^\d+\.\d+\.\d+$`로 고르고 RC 네 개를 따로 센다. `NotesMarkdown`이 있는 버전은 20개이고 그중 18개는 통합 이력과 겹친다. GH 원장의 Desktop 27개와 합치면 설명이 있는 버전은 29개다.
2. 통합 원장은 commit `09a6a47e43787ff36e751eae6c5015ce8d8b9d94`로 고정했다. `releases[].id`로 중복을 제거하고 `component`, `changes[].type`, `changes[].entries[].breaking`을 합산한다. 공식 JSON의 SHA-256은 `d7a259762c8c6b12e3a05e6cae90fc93b4a4814ea1338543a8783f01bba8bd17`이다. [고정 JSON 원본](https://raw.githubusercontent.com/griptape-ai/griptape-nodes-changelog/09a6a47e43787ff36e751eae6c5015ce8d8b9d94/changelog.json)

Windows 0.31.0 패키지는 Stable 원장의 Full 자산 SHA-256 `26939b3fa70cf9d355c05b2a86594177e5df6949aa7c5ec2c6f24794f0c748e3`와 로컬 캐시가 일치했다. `resources/app.asar` 해시는 `01749103f8e298d28bd0632a8cd7f57ec1a0aed09e2eeb7f4fcc1ec8208725d3`이다. 4. 옛 구성 버전은 각 Stable Full 패키지 URL에서 ZIP 끝 22바이트와 중앙 디렉터리 시작 최대 128 KiB를 범위 조회하고, `resources/engine-bundle/.version`, `.engine-version`, `.editor-version`이 있으면 그 파일만 읽었다. 현재 설치본은 같은 세 파일로 직접 대조했다. 기간 중 모든 OS의 패키지를 설치하거나 과거 릴리스의 HMB 버튼을 실행한 검사는 아니다.
