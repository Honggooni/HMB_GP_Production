# HMB 연결 관리

헤더에서 잠금 아이콘 왼쪽의 체인 **연결 관리** 버튼을 누른다. 접힌 캡슐에서는 우클릭 메뉴의 **연결 관리**를 사용한다. 연결된 노드 삭제가 거절됐을 때 표시되는 알림에서도 이 창을 열 수 있다.

창에는 실제 연결선과 REMOTE 연결 대상, 연결된 샷이 표시된다. **연결 해제**는 선택한 도구에 연결된 관계를 해제하고 자동 재연결을 막는다. 다른 도구 사이의 관계는 유지한다. 샷의 입력·설정·프롬프트·기존 결과·Task ID를 삭제하지 않는다.

해제 상태를 워크플로와 함께 저장하면 다시 열어도 해제 상태를 유지한다. **다시 연결**은 기억한 원래 노드와 샷을 검증해 복구하며 렌더를 시작하지 않는다. 원래 대상이 삭제됐거나 다른 노드로 바뀐 경우, 입력 포트가 다른 연결에 점유된 경우에는 복구하지 않고 이유를 표시한다. 같은 이름의 새 노드를 원본으로 간주하지 않는다.

해제한 상대를 삭제한 경우 남은 도구에서 **삭제된 연결 기록 정리**를 사용한다. 삭제된 상대의 복구 기록만 정리하며 입력·결과는 유지한다. 이후 기존 샷 설정에 따른 연결 검색이 다시 허용되므로, 사용할 샷과 상대를 확인한 뒤 작업한다. 살아 있는 상대의 일시 해제 기록이나 식별자가 중복된 노드에는 이 기능을 적용하지 않는다.

노드를 없애려면 먼저 연결을 해제한 후 별도로 삭제한다. 연결이 남은 HMB 도구는 휴지통·Delete 키·우클릭·그룹/일괄 삭제·엔진 삭제 경로에서 보호한다. 연결 없는 도구는 기존 삭제 기능을 사용할 수 있다.

연결 조회·해제·다시 연결은 생성·업로드 명령을 실행하지 않는다. 실행 중인 관련 작업이 있으면 먼저 작업이 끝난 뒤 사용한다.

2026-10-24 Local v0.8.30에 적용했다. 실제 Griptape에서 연결 목록 조회, 삭제 차단, 연결 해제 상태 저장·재오픈과 원래 연결 복구를 확인했다. 상세 검수 범위는 `reports/predeploy-usability-fixes-20261024/release-status.md`를 참고한다.
